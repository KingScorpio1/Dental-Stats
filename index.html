Situation 1: Nitrate levels in Hypertensive Patients

Healthy ($n_1=4$): 0.97, 0.95, 0.92, 0.89

Hypertensive ($n_2=5$): 0.60, 0.81, 0.77, 0.67, 0.74

Q1-Q5: F-Test for Homogeneity of Variances ▼
$$H_0: \sigma_1^2 = \sigma_2^2 \quad \text{vs} \quad H_1: \sigma_1^2 \neq \sigma_2^2$$ $$s_1^2 = 0.0012, \quad s_2^2 = 0.0070$$ $$F_{calc} = \frac{s_1^2}{s_2^2} = \frac{0.0012}{0.0070} = 0.1757$$ $$df_1 = 3, \quad df_2 = 4$$ $$\text{Acceptance Interval: } [0.0662, 9.98]$$ $$\text{Decision: Fail to reject } H_0. \text{ Variances can be assumed equal.}$$
Q6-Q10: Pooled t-Test for Equality of Means ▼
$$H_0: \mu_1 = \mu_2 \quad \text{vs} \quad H_1: \mu_1 > \mu_2$$ $$s_p^2 = 0.0045 \implies s_p = 0.0671$$ $$t_{calc} = \frac{0.9325 - 0.718}{0.0671 \sqrt{1/4 + 1/5}} = 4.7654$$ $$df = 7. \quad t_{crit, 0.95} = 1.895 \implies \text{Acceptance Interval } (-\infty, 1.895]$$ $$\text{Decision: Reject } H_0. \text{ Healthy individuals have higher NO levels.}$$

Q15-Q22: Chi-Square Test of Independence ▼
$$H_0: \text{Variables are independent} \quad H_1: \text{There is an association}$$ $$E_{NaOCl, Adverse} = \frac{41 \cdot 215}{946} = 9.32 \quad E_{EDTA, Adverse} = \frac{41 \cdot 320}{946} = 13.87$$ $$\chi^2 = \sum \frac{(O-E)^2}{E} = 6.3842$$ $$df = (2-1)\cdot(3-1) = 2. \quad \chi^2_{crit} = 5.991 \implies \text{Acceptance Interval } [0, 5.991]$$ $$\text{Decision: Reject } H_0. \text{ Significant association between irrigant and events.}$$

Q23: Mean-Centred Interval (Central 97%) ▼
$$\text{Tails size: } \alpha/2 = (1-0.97)/2 = 0.015 \implies z = 2.17$$ $$x_{lower} = \mu - z\sigma = 1.5 - (2.17 \cdot 0.3) = 0.849$$ $$x_{upper} = \mu + z\sigma = 1.5 + (2.17 \cdot 0.3) = 2.151$$ $$\text{Interval: } [0.849, 2.151] \text{ nM}$$
